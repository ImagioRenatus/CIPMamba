# CIPMamba: Conditioning Selective State-Space Modeling on Content and Illumination for Low-Light RAW-to-sRGB Restoration

CIPMamba is a two-stage framework for low-light RAW-to-sRGB image restoration. It incorporates content and illumination-related contexts into selective state-space modeling through joint prompt conditioning.
